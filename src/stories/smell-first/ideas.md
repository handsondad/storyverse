# 小小食物鉴赏家

## 发生了什么（2026-02-09，小念一岁半）

- 最近小念对食物的味道有了感觉，吃东西的时候还要闻一闻，非常有趣。
- 一次吃饭，看到姜（姥爷爱吃姜，炒菜放得比较多）。不知道什么时候，小念就知道姥爷爱吃姜了，拿着姜说「姜」，就往姥爷嘴里放。
- 姥爷说你吃不吃，小念闻了闻，皱着眉说「辣」，表情非常搞笑。
- 一会儿他又看到蒜了，拿起来又闻了闻，结果就吃起来了。其实蒜也辣（可能是姥爷炒熟了，就不辣了），爸爸尝了尝，果然是。
- 看来小念的鼻子还挺厉害，以后每次吃一个新东西，他都先闻一闻，才说吃或不吃！
- 妈妈说这是小小食物鉴赏家啦！

## 画的时候定下的

- 新姿势 `sniff`：两手把东西举到鼻子前闻（配 `hold`）；新表情 `yuck`：皱着眉、挤着眼、嘴巴歪歪。
- 小念一岁半，只给他一个字的话：「姜！」「辣！」都是原话。
- 原话：姥爷「你吃不吃？」，妈妈「小小食物鉴赏家啦！」。
- 新加的台词：妈妈「吃之前还要闻一闻！」，爸爸「蒜不辣吗？」「炒熟了，真不辣！」，拟声字「嗅嗅」「哈哈哈！」「吧唧吧唧」。
- 最后一格闻的是草莓 🍓，代表「每一样新东西」。
