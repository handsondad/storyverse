# 眼睛肿了

## 发生了什么（2025-06-09，小念十个月）

- 最近小念眼睛有点肿，一开始爸爸妈妈都认为是蚊虫叮咬。
- 几天了都不见好。
- 有个阿姨看到小念眼肿，说是麦粒肿。爸爸听了还摸不着头脑，一点这个知识和概念都没有。
- 所以决定带小念去医院看看。
- 到了医院，医生阿姨才和爸爸妈妈详细说明这个情况：是麦粒肿，可能和不卫生有关。
- 给小念开了一点眼药，让先观察下，看看后面要是严重再去。
- 结果小念的抵抗力比较强，的确过了几天好了。
- 哎，爸爸真是不懂啊，幸亏遇见那个阿姨。

## 画的时候定下的

- 小念这时才十个月，还是宝宝：一律用 `thing: { kind: "baby", move: "sit", hair: "fuzz" }` 画，坐着或抱在妈妈怀里；**不要**用站立的 `who: "nian"` 角色。他还不会说话，没有气泡，只用旁白和「嗯！嗯！」的音效。
- 眼肿没有现成表情，靠 `sick: true`（小脸红红的、没精神）和旁白「老是揉眼睛」来表达；一开始以为是蚊子咬的猜想也写进旁白。
- 外面遇到的阿姨用 `ayi`，医生阿姨用 `ayi` 加 `outfit: "doctor"`（白大褂），都不另建角色、不署名。
- 医院走廊用 `place: "hospital"`，门牌写 `sign: "眼科"`。
- 眼药用药盒 `thing: { kind: "box", label: "眼药" }`，放在医生手里（前面）。
- 台词改成孩子听得懂的短句；爸爸那句「麦粒肿？那是什么？」要画出他一头雾水；结尾留爸爸那句感叹「唉，爸爸真是不懂啊！」。
